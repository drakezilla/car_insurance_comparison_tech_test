### App architecture
Este fichero define los conceptos basicos de la arquitectura del sistema

## Tech Stack
El tech stack esta compuesto por
* Vue 3.5: el framework de eleccion para la parte del frontend
* Symfony 8.1: el framework de eleccion para la parte de backend

## basic components
La aplicacion tiene 2 elementos importantes
* Frontend: desarrollado en su totalidad en vue. Contiene una pagina frontal simple con un formulario que preparará al cliente en su busqueda de un nuevo seguro para su coche rellenando algunos datos simples
* Backend: desarrollado en symfony provee de un endpoint que prepara una respuesta comun para todos los posibles proveedores desiponibles en la busqueda de un seguro de coches
